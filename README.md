# M-Pesa Sign-In UI (Exam)

Quick notes and how to run.

## Architecture
- Small Flutter app with simple MVVM-ish separation: `main.dart` (screens + API call) and `home.dart` (UI). Kept minimal for the short deliverable.

## Packages
- `http`: API requests
- `iconsax`: icon set per requirement

## How to run
1. Ensure Flutter SDK installed
2. Run:

```bash
cd C:/Users/hp/Desktop/mpesa
flutter pub get
flutter run -d chrome
```

## AI usage
- Used Copilot-like assistance to accelerate UI and wiring.
